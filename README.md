**Fitur tambahan pada Mini Game RPG**
1. Menerapkan exception, try, dan catch
2. Jika input selain angka, maka akan mengeluarkan pesan error dan loop kembali.
3. Jika menyerang musuh yang sudah tewas, maka akan mengeluarkan pesan error dan loop kembali.
4. Jika input power tidak sesuai, maka akan mengeluarkan pesan error dan loop kembali.
